# Luna 2.1.2 karakter önizlemesi

Bu önizleme canlı uygulamaya bağlı değildir; localStorage veya IndexedDB okumaz/yazmaz.

- characters.svg: yeni gerçek sprite dizilerinden üretilen altı durumluk görsel pano.
- characters.html: indirip tarayıcıda açılabilen, tek dosyalık etkileşimli karakter sahnesi. İnternet gerekmez. Karakter, duygu, saat ve hareket azaltma kontrolleri vardır.
- Görseller js/scene.js içindeki aynı yüz dizilerinden üretilmiştir. Demo yerleşimi sadeleştirilmiştir; uygulama güneş yüksekliğini kullanırken demo karanlık sınırını 19:00 olarak alır.

Geliştiren: Çağan Sezer Karaman.

Bu dal gözden geçirilmeden yayın dalına birleştirilmemelidir. Hedef sürüm: 2.1.2. Mevcut canlı sürüm: 2.1.1.
