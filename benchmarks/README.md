# benchmarks/

Performance measurements and recorded verification results.

* `poisson_solvers.cpp` — `aerion-bench-poisson`. It times the Poisson linear
  solvers and checks the discretisation error of every timed solve.
* `results/<stage>/` — results recorded at the end of each development stage,
  with the exact commands, revision and machine description. Files in there
  are generated by the tools, never edited by hand.

Recorded so far:

| stage | content |
|---|---|
| [stage1](results/stage1/README.md) | Poisson order-of-accuracy studies (uniform/stretched, CG/SOR) and solver timings |

Run the benchmark yourself:

```bash
cmake --preset release && cmake --build --preset release
./build/release/benchmarks/aerion-bench-poisson --max-n 512 --threads 4
```
